# Supported games

NeledPort knows **72 games**. Any other Steam dedicated server works through **Any Steam App ID**, which also searches 380 more servers by name.

**full** means everything the game's own dedicated server offers, checked against its official docs, its source, or
[LinuxGSM](https://github.com/GameServerManagers/LinuxGSM): a stop that saves the world, the player list, kick and bans, a
console, config files, backups and a one-click mod loader, where the game has them. "Extras" lists what each game has; a
game without a remote console still gets launchers, settings, config files and backups. "OS" lists the platforms whose
launcher is known; on other systems you pick the program once after installing and can share it back.

"Real server" = installed, started, controlled and stopped by the weekly [real-server workflow](../.github/workflows/e2e.yml).
"—" means not tested on a real server yet (some need a Steam account that owns the game, or more than a CI machine has).

Missing a game, or tested one? See [CONTRIBUTING](../CONTRIBUTING.md#add-a-game). This file is generated by `scripts/import-catalog.mjs`.
